# Repository instructions

This repository is rooted at `~/.pi`; the active Pi profile is `agent/`.
Read `agent/AGENTS.md` for the current routing, module loading, worker control and attribution instructions when working on this profile. Do not restore the retired root-level GSD, skills or extensions as additional active tooling.

Keep authentication, sessions, installed dependencies, caches, backups and machine-local configuration out of commits. Use configuration examples for shareable settings. Preserve existing local sign-ins and configuration during updates.

Create a feature branch and pull request against `master`; never push directly to `master`.
