## LEARN procedure
Run only when durable knowledge is worth preserving.

Capture only stable, reusable truth:
- accepted architectural/project decision;
- confirmed invariant;
- recurring debugging/testing lesson;
- durable navigation/operational knowledge.

Do not summarize the session or store temporary state.
Use the narrowest authoritative destination.
Load `references/extended.md` only for complex knowledge reconciliation.

Resolve relative references from this module folder. This procedure supplies guidance; the selected named role still must actually run.
