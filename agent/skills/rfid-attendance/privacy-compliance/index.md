# privacy-compliance

Use for unresolved data-minimization, retention, disclosure, export or privacy behavior involving students/parents. The named role is `privacy-compliance-specialist`.

## Required analysis
Inventory only task-relevant data classes, such as:
- student identity and attendance history;
- parent/guardian contact information;
- RFID/card identifiers;
- reader/device metadata;
- operator/admin identity and audit trails;
- notification content/status;
- logs, exports and backups.

For each material data class establish purpose, access audience, retention expectation, logging/export exposure, backup implications, deletion/anonymization behavior and audit needs.

Do not state jurisdiction-specific legal conclusions unless authoritative requirements are supplied. Separate project policy from questions requiring qualified legal advice. Security controls such as auth/authz/secrets remain `security-specialist` ownership.

Read `guide.md` only for deeper data-flow/retention review.
