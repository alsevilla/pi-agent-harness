# Sources for Accessible UI Patterns

This skill is a curated local operating guide, not a replacement for the standards.

Authoritative / primary references checked for this compilation:

- WCAG 2.2 — W3C Web Accessibility Initiative
  https://www.w3.org/TR/WCAG22/
- WAI-ARIA Authoring Practices Guide — W3C WAI
  https://www.w3.org/WAI/ARIA/apg/
- APG: Developing a Keyboard Interface
  https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/
- web.dev: Interaction to Next Paint (INP)
  https://web.dev/articles/inp
- web.dev accessibility/motion guidance
  https://web.dev/prefers-reduced-motion/

Use the current authoritative source when a requirement depends on exact conformance language.
