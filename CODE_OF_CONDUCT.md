# Code of Conduct

This is a small, volunteer-maintained harness profile. Everyone who uses, reports on or contributes to it is expected to follow these rules.

## Expected behavior

- Be respectful and constructive in issues, pull requests, reviews and discussions.
- Do not harass, threaten, discriminate against or personally attack anyone.
- Respect privacy. Do not publish others' personal data, including student, parent, staff or RFID-related records, private messages or session content, without clear permission and a legitimate need.
- Never post secrets, tokens, passwords, credentials or private machine-specific paths. If one is exposed, report it and rotate it.

## Scope

This applies to repository spaces (issues, pull requests, reviews, discussions and commit messages) and to representing the project in public.

## Enforcement

Maintainers choose a proportionate response. Options include:

1. a warning and a request to change behavior;
2. a temporary restriction from participation;
3. removal of content, commits or access.

Severe or repeated conduct may skip earlier steps. Maintainers should consider context and give the affected person a chance to respond when practical. Content that exposes private or sensitive data may be removed directly.

## Reporting

Report concerns to the repository maintainer, identified by their public GitHub profile: https://github.com/alsevilla. This repository does not publish a private reporting address or channel. If the maintainer publishes one, use it. Otherwise, do not post sensitive details publicly. Open a public issue that only asks the maintainer for a private contact, with no personal data, secrets or other details. The GitHub profile identifies the maintainer; it does not offer a messaging channel for reports. Include links and dates when sharing the details privately.
